## Reporting and testing

A useful report names the model, OS, DAW, fork commit, sample rate, buffer, USB connection, exact failing step and sanitized logs. Distinguish device detection, successful replies, bank sync, note transmission and returned audio. Do not test by flooding MIDI, updating firmware or overwriting stored patches.

The full plug-in scan of a DAW can invoke unrelated products' authorization windows. For a focused reproduction, first use the explicit-bundle host in [PERFORMANCE.md](PERFORMANCE.md). It does not scan other AU/VST products.
